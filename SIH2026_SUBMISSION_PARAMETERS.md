3. CORE TECHNICAL INNOVATIONS & ALGORITHMIC FORMULATIONS
================================================================================

3.1 Generalized Open-Vocabulary Compound Spatial Search
To resolve the "average vector trap" without relying on brittle hardcoded keyword lists, Diachron AI incorporates a three-stage generalized mathematical formulation:

Stage 1: Open-Vocabulary Syntactic Dependency Parsing
User prompts are parsed into syntactic heads and modifiers using part-of-speech dependency trees:
- Target Concept (T): e.g., "construction", "bunker", "airstrip", "vehicle depot"
- Spatial Relation (R): e.g., "near", "along", "adjacent to", "within"
- Anchor Concept (A): e.g., "river", "border line", "highway", "ridgeline"

Stage 2: Harmonic Co-Occurrence Scoring
Independent embedding vectors are generated for Target Concept (q_T) and Anchor Concept (q_A). For every candidate scene i in the archive, cosine similarities S_T(i) and S_A(i) are computed against the image embedding matrix. Rather than computing an arithmetic mean (which tolerates the total absence of one concept), Diachron AI computes the Harmonic Mean:

    S_cooccur(i) = [ 2 · S_T(i) · S_A(i) ] / [ S_T(i) + S_A(i) + ε ]

The harmonic mean naturally penalizes severe imbalances: if either the target or the anchor similarity approaches zero, S_cooccur collapses toward zero.

Stage 3: 4×4 Spatial Quadrant Activation Distance
To guarantee spatial proximity within the scene, the raster is partitioned into a 4×4 grid of spatial quadrants {Q_1, ..., Q_16}. Spatial embeddings are evaluated across each quadrant to find the minimum grid Chebyshev distance between the maximum activation of T and A:

    d_min = min_{j, k} ||coord(Q_j) - coord(Q_k)||_∞  such that  Act(T, Q_j) > θ_T  and  Act(A, Q_k) > θ_A

The final compound score is formulated as:

    Score_final(i) = S_cooccur(i) · exp( -λ · d_min )

This mathematical pipeline operates across arbitrary geospatial concepts without requiring pre-configured rules.


3.2 Dual-Layer Quality Screening & Autonomous SAR Radar Arbitration
To eradicate false alarms caused by cloud, haze, shadow, and seasonal phenology, Diachron AI combines optical spectral masking with Synthetic Aperture Radar (SAR) physics:

Layer 1: Vectorized Optical Atmospheric Masking
Multi-spectral bands are processed at 10m Ground Sampling Distance (GSD):
- Cloud Detection: Evaluates Rayleigh blue-band atmospheric scattering (B02 > 0.20) and spectral whiteness index W = Σ|B_i - B_mean| / B_mean.
- Cloud Shadow Detection: Evaluates near-infrared (NIR) absorption drops (B08 < 0.12) combined with morphological dilation along the solar azimuth angle.
- Water Masking: Evaluates Normalized Difference Water Index (NDWI = (B03 - B08)/(B03 + B08) > 0.0).

Layer 2: Autonomous Sentinel-1 / RISAT-1A C-Band SAR Decibel Backscatter Arbiter
When an optical change candidate falls within a flagged cloud, shadow, or ambiguous region, the central controller automatically triggers the SAR Radar Arbiter. The system retrieves co-registered pre- and post-event Ground Range Detected (GRD) C-band radar passes (VV and VH polarizations).

Radar backscatter intensity is calibrated to sigma-nought (σ⁰) in decibels:

    σ⁰_dB = 10 · log10( DN² ) + Calibration_Constant

The decibel backscatter difference is calculated across epochs:

    ΔVV_dB = σ⁰_post,VV(dB) - σ⁰_pre,VV(dB)

The SAR Arbiter applies rigorous microwave electromagnetic scattering physics:
- Physical Ground Construction: New vertical structures, reinforced concrete installations, and metal sheds induce double-bounce corner reflection between the ground and vertical walls. This produces a massive backscatter surge:
      ΔVV_dB ≥ +3.0 dB  ──►  CONFIRMED PHYSICAL CHANGE (Confidence = 0.95)
- Atmospheric False Alarm: Clouds, fog, smoke, and shadows are completely transparent to C-band (5.405 GHz, ~5.6 cm wavelength) radar microwaves. If optical spectral deltas indicate change but radar backscatter remains invariant:
      |ΔVV_dB| < 1.5 dB  ──►  SUPPRESSED FALSE ALARM (Classified as Cloud/Shadow)
- Flood & Inundation: Standing water creates specular reflection, scattering microwave pulses away from the radar antenna. This produces a severe drop in backscatter:
      ΔVV_dB ≤ -3.5 dB  ──►  CONFIRMED INUNDATION / FLOOD EVENT


3.3 Bi-Temporal Siamese ChangeFormer & Sub-Pixel Coregistration
For high-fidelity bi-temporal change mapping:
- Sub-Pixel Phase Cross-Correlation: Pre- and post-event rasters undergo Fourier-domain sub-pixel phase cross-correlation. If co-registration residual shift exceeds 0.5 pixels, automated translation resampling is applied; pairs with irreconcilable distortion are safely flagged.
- Siamese Transformer Architecture: A dual-branch Mix-FFN hierarchical Transformer encoder processes pre-change (T1) and post-change (T2) optical passes. Multi-scale feature difference maps are computed at 1/4, 1/8, 1/16, and 1/32 resolutions, followed by a lightweight multi-layer perceptron (MLP) decoder.
- Multi-Index Spectral Ensembling: ChangeFormer predictions are ensembled with normalized spectral deltas:
      ΔNDVI = NDVI_T2 - NDVI_T1   (Vegetation Loss / Clearing)
      ΔBSI  = BSI_T2 - BSI_T1     (Bare Soil & Built-Up Expansion)
      ΔNDWI = NDWI_T2 - NDWI_T1   (Water Extent & Hydrological Dynamics)
- Adaptive Otsu Thresholding & Contour Polygonization: Continuous difference maps are binarized using adaptive Otsu thresholding, processed through morphological closing to remove salt-and-pepper noise, and traced into GeoJSON polygon features with precise ground area (hectares) and centroid coordinates.


3.4 Active Learning Analyst Feedback Loop (Rocchio Centroid Shift)
To empower defense analysts and continuously improve retrieval precision, Diachron AI integrates an interactive active learning engine based on the Rocchio algorithm:

Each retrieval candidate is characterized by a 12-dimensional feature vector x_i comprising:
[ S_cosine, S_harmonic, d_min, Area_ha, Change_conf, Cloud_cov, SAR_ΔVV, SAR_ΔVH, ΔNDVI, ΔBSI, ΔNDWI, Temporal_delta ]

When an analyst reviews candidates in the UI and applies verdicts ("Confirm" or "Reject"), the system updates the optimal query profile vector q_m:

    q_m = α · q_0 + (β / |D_R|) · Σ_{d_j ∈ D_R} d_j - (γ / |D_NR|) · Σ_{d_k ∈ D_NR} d_k

Where:
- q_0 is the original query feature vector (α = 1.0)
- D_R is the set of analyst-confirmed relevant candidates (β = 0.75)
- D_NR is the set of analyst-rejected non-relevant candidates (γ = 0.25)

The updated query profile q_m immediately rescores and reranks all pending candidates in 0.006 ms. The UI renders explainable rank trajectory indicators (e.g., "▲ +4 positions", "▼ -8 positions") alongside the driving feature attribution. Every analyst interaction is immutably logged in an ISO 19115 compliant JSON audit trail.
